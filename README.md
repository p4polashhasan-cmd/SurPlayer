# Sur (সুর) – লোকাল মিউজিক প্লেয়ার

Kotlin + Jetpack Compose + Media3 (ExoPlayer)। কোডটা সম্পূর্ণ নতুন করে লেখা, অন্য কোনো অ্যাপের কোড বা অ্যাসেট নেই।

## চালানোর ধাপ
1. Android Studio (Ladybug বা নতুন) ইন্সটল করুন।
2. File → Open → `SurPlayer` ফোল্ডারটি খুলুন। প্রথমবার Gradle sync-এ ইন্টারনেট লাগবে।
3. ফোন USB দিয়ে লাগান (Developer options → USB debugging চালু), তারপর Run ▶।
4. APK চাইলে: Build → Build Bundle(s)/APK(s) → Build APK(s)।

## ফিচার
- ফোনের সব গান স্ক্যান, সার্চ, ফিল্টার (সম্প্রতি শোনা, বেশি শোনা, পছন্দের, অপছন্দের, নতুন যোগ)
- Now Playing: অ্যালবাম আর্ট থেকে রঙ নিয়ে ব্যাকগ্রাউন্ড গ্রেডিয়েন্ট, ওয়েভফর্ম-স্টাইল সিক বার
- Play/pause, next/prev, shuffle, repeat (off/all/one), 👍/👎 রেটিং
- Sleep timer (১৫/৩০/৪৫/৬০ মিনিট)
- Equalizer (ব্যান্ড স্লাইডার + প্রিসেট), Bass boost, Loudness gain
- ব্যাকগ্রাউন্ড প্লে, নোটিফিকেশন ও লক-স্ক্রিন কন্ট্রোল, হেডফোন খুললে অটো পজ

## জানা সীমাবদ্ধতা / পরের ধাপ
- ইকুয়ালাইজারের ব্যান্ড সংখ্যা ফোনের হার্ডওয়্যারের ওপর নির্ভর করে (সাধারণত ৫টি)।
- EQ সেটিং অ্যাপ বন্ধ করলে সেভ হয় না (পরে DataStore দিয়ে করা যাবে)।
- ওয়েভফর্মের আকৃতি সাজসজ্জার, আসল অডিও থেকে আঁকা নয়।
- প্লেলিস্ট, লিরিক্স, ফোল্ডার ব্রাউজিং এখনো নেই।
